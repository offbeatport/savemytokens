Decide which project gets your Claude allowance.

Node 18.17+ · zero dependencies · nothing leaves your machine

What it does

The real numbers

Your 5-hour and weekly usage exactly as Anthropic publishes it, read from the Claude Code status line. Never an invented “% remaining”.

Two lists you control

ACTIVE is what shares your window. A project joins it when you open Claude Code there and stays after you close it, so a target survives the session. RECENT is everything else; press a to move one up.

Claude working to it

As a session eats into its slice it is told to narrow scope and finish, and to write down whatever it drops. That comes back next time you open the project.

Unused capacity returned

A project with nothing running lends its share to the rest and takes it back when you return. Mark one done and what it did not spend goes to the others immediately.

Works with

Claude Codesupported Hooks and a status line, reading the 5-hour and weekly windows Anthropic publishes. Codexsoon Codex publishes its own rate limits, so visibility is close. A share it can act on needs somewhere to inject the advice. Gemini CLIsoon Not started. It ships when there is a published quota to read, rather than a number to guess at. Grok CLIsoon Not started. Same bar as the others: a real published window, or it does not ship.

Where the numbers come from

Published 5h and 7d usage, straight from Anthropic through the status line. We do not estimate it and we do not adjust it.
Measured Tokens per project, counted from the transcripts already on your disk. Nothing is sampled and nothing is sent anywhere.
Inferred The split between projects. Anthropic publishes one total, so dividing it by measured share is ours, and we label it as ours.

Install

npx savemytokens Opens the control centre and offers to install on first run.
… install Four hooks and a status line in settings.json, backed up first. Without them nothing is live.
… uninstall Removes every entry it added and restores a status line it wrapped.
… status One plain-text snapshot, or --json for a script.

What it will not do

  • It cannot stop a session. There is no API to pause Claude Code, so a share is advice given to Claude, not a hard cap.
  • It does not predict a lockout. Anthropic publishes a percentage and a reset time; anything past that would be a guess.
  • It makes no network call. No account, no telemetry, no daemon. Everything lives in ~/.savemytokens.
